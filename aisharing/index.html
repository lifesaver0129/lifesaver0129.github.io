近期 AI 新能力 Update

本部分聚焦四类近期值得关注的 AI 能力演进，结合商业化广告场景，观察它们可能对流量变现、 广告策略、广告插入、广告形态优化和收入归因判断带来的新变量。

Trend 01 · Computer Use · 操作电脑能力

Computer Use：看屏幕、点按钮、操作软件

功能与能力

  • 读取屏幕内容，识别按钮、输入框、表格、图表、弹窗和页面状态。
  • 通过点击、输入、筛选、复制、下载、截图等界面操作完成任务。
  • 可以跨多个已有系统连续执行，尤其适用于缺少标准 API 的内部后台。
  • 主要适用于查询、核对、截图留证和信息汇总，不适合无人审核地执行高风险线上变更。

可能如何影响我们

  • 日常运营检查可以由 AI 先完成跨系统查询和证据整理，PM 聚焦异常判断。
  • 收入异常、实验配置、广告填充、素材状态等信息，可以更快形成可复核线索。
  • 对广告后台而言，短期价值更多在“辅助操作现有系统”，而不是替代核心策略服务。

Trend 02 · WebMCP / Agentic Web · Agent 可调用工具

WebMCP：网站把功能开放成 Agent 工具

功能与能力

  • 网站或 Web 应用主动声明可供 Agent 调用的结构化工具，而不是只提供人可点击的页面。
  • JavaScript functions、HTML forms 等能力可以被包装成机器可读、参数清晰、返回结果稳定的动作。
  • 典型能力包括查询、导出、对比、提交、模拟和审批，目标是提升 Agent 调用的速度、可靠性和可审计性。
  • 对内部系统，关键不只是“开放接口”，还包括权限、日志、口径说明和可回滚边界。

可能如何影响我们

  • 商业化后台可能逐步从“页面可用”演进到“Agent 可调用”，产品设计对象发生扩展。
  • BI、实验平台、广告策略平台需要明确哪些能力可查询、可模拟、可执行、必须审批。
  • 指标口径、实验规则、权限边界和操作日志，会成为系统设计中更重要的产品要素。

Trend 03 · Effort Control · 思考深度控制

Effort Control：控制模型思考深度和算力预算

功能与能力

  • Effort 参数用于控制模型在回答时投入多少推理和 token，在质量、速度和成本之间做取舍。
  • 低 effort 适合格式整理、文案润色、简单摘要；高 effort 适合多因素归因、策略判断和复杂解释。
  • 它让“模型思考深度”从隐性消耗变成可配置预算，便于按任务价值分配 AI 成本。
  • 在 token 限额下，需要减少无关上下文，优先提供目标、口径、关键字段和必要样本。

可能如何影响我们

  • 广告收入归因、实验放量、频控调整等任务，可以按风险和复杂度选择不同推理深度。
  • 低风险任务优先追求速度和成本；收入影响大、因果不确定的任务再使用高 effort。
  • 与 AI 协作会更强调“上下文工程”：数据先压缩、问题先拆解、结论再验证。
1
先压缩输入只保留指标口径、异常区间、实验分组和必要样本。
2
再选择 effort简单整理用低 effort，归因判断用高 effort。
3
结果验证要求输出证据、反例、置信度和待补充数据。

Token 使用建议：先给结论目标和字段口径；长材料先提取结构化摘要；复杂问题拆成“清洗、定位、归因、建议”多步处理。

Trend 04 · Agentic Commerce · AI 参与交易决策

Agentic Commerce：AI 参与选品、比较和购买

功能与能力

  • AI 开始参与商品发现、比较、加购、支付和售后支持，购买决策链路从人手动浏览扩展到 Agent 辅助执行。
  • Universal Commerce Protocol 等协议尝试让 Agent、商家系统和支付方使用共同语言完成交易动作。
  • 商品信息需要可被机器读取和比较，包括价格、库存、权益、评价、兼容性、退换货和履约状态。
  • 广告信息不只影响用户点击，也可能影响 AI 是否纳入候选、如何解释推荐、能否推动交易完成。

可能如何影响我们

  • 广告触达场景可能从页面曝光进一步延伸到 AI 参与的选品、比较、推荐和购买链路。
  • 广告素材需要同时面向用户和 Agent：用户关注表达，Agent 更关注价格、库存、权益、评价和履约证据。
  • 远期归因可能不只看点击和转化，还要识别 AI 是否参与推荐、解释、加购或支付决策。
1
理解需求把用户的预算、场景、偏好、限制条件转成可检索意图。
2
筛选候选基于价格、库存、评价、权益、兼容性先过滤商品或品牌。
3
对比证据比较卖点、评论、退换货、履约和可信度，而不只看创意。
4
推荐与购买给出推荐理由，并可能进一步进入加购、支付和履约链路。

商业化指标可以再延伸到 Agent Inclusion Rate、Agent Recommendation Share、Agent Citation Rate 和 Agent-mediated Conversion。
